# AirPassport Windows 跨平台接收器

专门为在 Windows 电脑（公司办公电脑/个人台式机）上使用 AirPassport 随身无线麦打造的轻量级接收客户端。

---

## ✨ 核心特性

1. **一键绑定 / 自由抢占**：
   - 界面上点击 **【⚡ 立即绑定 / 接管连接】**，自动捕获手里的 AirPassport 硬件并建立连接。
   - 自动保存已绑定的 MAC 地址，不会串连同事的设备。
2. **多电脑切换无缝流转**：
   - 离开 Windows 时，点击 **【⏸️ 释放 / 断开当前连接】**，AirPassport 瞬间释放，家里的 Mac 或另一台电脑能立即接管。
   - 也可以在硬件上**双击中键（OK键）**主动断开并重新广播。
3. **原生按键模拟**：
   - **顶键（UP）**：按住讲话（模拟 Alt 键，开启 16kHz 无线麦录音并实时推流）。
   - **底键（DOWN）**：单击直接触发 Windows 回车键（Enter / 发送）。
   - **长按底键 1.5 秒**：打开 WiFi 配网页面。
4. **高质量音频保存**：
   - 每次松手后，完整语音自动保存至 `recordings_windows/` 目录下（WAV 格式）。

---

## 🚀 使用方法

### 方法 A：直接双击运行（有 Python 环境）
1. 确保电脑已安装 Python 3.8+ 并开启蓝牙。
2. 双击运行 `run.bat`（会自动安装依赖并启动窗口）。

### 方法 B：打包成绿色单文件 EXE（最推荐）
1. 双击运行 `build_exe.bat`。
2. 稍等片刻，在 `dist/` 文件夹下生成 `AirPassport.exe`。
3. 把 `AirPassport.exe` 拷到任意 Windows 电脑，双击直接运行，无需安装任何环境！
