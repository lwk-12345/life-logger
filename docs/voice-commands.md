# Life Logger 口令词对照表

> 目的：让你（或第一次用这个系统的人）知道**说哪些话会被系统特殊处理**、会产生什么行为。
> 路径约定：不带前缀的都在 `src/life_logger/`。
> 生成时间：2026-10-12。所有条目均有代码位置可查。

---

## 一句话口诀

**「记录一下 / 记一下 / 查一下 / 检查一下 / 提醒我」+ 具体内容**，
把口令和内容放在**同一句**里，或者口令之后 25 秒内继续说（手表链路会把后面最多 3 句本人语音拼进来）。
口令必须是**你自己**说的（系统先判说话人）。

## 7. 给人看的说明：想让它记住/查东西，这么说才有效

**1. 想让它记住 → 口令 + 内容，一句话里说完**
说「**记录一下** + 内容」或「**记一下** + 内容」最稳（两个词在多条链路都认）。说了这个口令，那条内容会**跳过人工复核、跳过置信度闸门**直接进正式记录，并挂上「便签」标记。反过来，不喊口令普通说一句话，置信度低于 0.80 的内容会被直接丢掉。

**2. 想让它查/干活 → 「查一下 / 检查一下 / 帮我查 + 具体问题」**
这不只会记一条待办，还会**真的往 OpenClaw 派一条 P1 任务**（标题「【语音自查】…」，带微信转发标记）。「查询一下」「调查一下」「问一下」「自查一下」同效。
新加的兜底：只要是「检查/查询/查/记录/记/备忘/汇报/整理/总结/统计/分析 + 一下/一遍/下」的祈使句，模型判成"没有事件"也不会静默消失，会转成待确认。**但这只救祈使句，陈述句（"我今天检查了系统"）不救。**

**3. 想记钱 → 说金额 +「元/块」**
「记一笔」「记账」会把它升格成主动模式。两条禁忌：①说「以前/当时/去年买的」「划算吗/值不值」——系统会判成闲聊或经验分享，**不记当天消费**；②金额必须是你确实说出口的数字。

**4. 想让它当待办 → 「提醒我 / 记个待办 / 记个todo」**
这四个词是硬触发。**别用**「你要记得…」「我记得当时…」「印象中…」——这些是硬排除词，反而不会生成待办。同一件事隔 15 分钟内说两遍会被合并成一条。

**5. 千万别说的句式（说了会没反应）**
- 「**汇报一下现在…**」——被列进「对着电脑说话」的语义标记表，会被当指令剔除
- 「**我吃了一口**」「**我看你**」——在幻觉词表里，**整句消失**
- 「**没记吗**」「你都没记吗」——在 meta 调试词表里，抱怨也丢
- 「**单声道**」「**双声道**」「声纹识别」「模型内核」——开发测试用语，一律判为调试杂音

**6. 一句口诀**
「**记录一下 / 记一下 / 查一下 / 检查一下 / 提醒我** + 具体内容」——把内容和口令放在同一句，或者口令后 25 秒内继续说。口令必须是**你自己**说的；含「吃了/喝了/花了/买了/待办/提醒我/记录一下」等生活信号的句子有额外的防误删保护，值得优先用这些词。
