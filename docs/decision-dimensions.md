# 十一维决策注解：生产提取契约

实现：`src/life_logger/decision_dimensions.py`；接入：`contextual_extraction.py`。版本 `life-decision-dimensions-v1`。十一维是十一组信息，其中本人和新事分成子问题，共15个choice问题；Kev的现有接口及Jev的choice接口均可表达该问题格式，当前生产集成仍使用本地Kev，未新增云端调用或自动升级。

## 定义与用途

| 信息组 | 判什么 | 如何使用 |
| --- | --- | --- |
| media | 疑似媒体/现场讲话/未知 | 提供来源线索，不替代声学判断或删原文 |
| self | 说话人声学归属；事件主体本人/他人/混合/未知 | 说话人由现有source_label决定，文本不能把unknown升为self；主体供后续抽取核对 |
| novelty | 可记录信息、与历史关系、完整性、表达性质 | 事实/计划/想法/问题/否定/混合分开；历史未提供时关系强制unknown，碎片等待上下文 |
| people | 是否明确有真人参与/托付 | 关注参与者和承诺，AI和节目角色不算现场真人 |
| goal | 是否与配置的用户目标有关 | 关注相关目标证据；不评价成功/失败；目标可配置，空列表则unknown |
| health | 症状/行为/两者/无关/未知 | 保留原话状态与行为，不打健康正负分、不诊断 |
| expense | 消费类别/无/未知 | 关注购买和付款状态；吃喝不自动等于花钱，计划购买不等于付款 |
| amount | 明示金额/消费未说金额/无/未知 | 引导提取数值、币种、净实付；不再按50元分档，准确金额仍由原文校验 |
| quantity | 明确/模糊/无/未知 | 关注数量、单位、对应对象；口头助词不当数量 |
| location | 明示事件地点/有上下文依据/无/未知 | 后续提取事件地点；不能把当前WiFi直接套给过去事件 |
| timeline | 现在/今天早些/昨天/更早/未来/混合/未知 | 后续抽取事件时间；录音时刻不是事件时刻 |

地点/时间重新作为语义线索保留在十一组中；系统传入录音时间，模型不猜具体坐标或钟点。旧V14移出的维度与新契约不是直接可比的旧金标。

## 数据流及边界

1. 准备原文、已有声源归属、同录音前后句、配置目标、调用方实际提供的历史意图。
2. 决策模型返回typed answers。合法选项、置信度、身份与历史边界由程序检查。
3. 完整结果保存在`context-extraction.json.decision_annotations[source_id]`，报告包含`decision_annotation_schema`和`kev.annotation_mode`。
4. 后续本地/远程抽取请求携带紧凑`decision_hints`，不重复整份`kev_annotation`。
5. 置信度低于门槛时`value=unknown`，合法候选另存`suggested_value`；传给抽取器时表示为`{suggested: ..., uncertain: true}`。弱信号只扩大关注字段，不供给事实。未经真实样本校准，不能把该置信度当成实际正确率。
6. 多维模式强制关闭丢弃门控，即使旧event_gate或任务参数仍为true。故障时原文继续提取；注解不改变身份、金额、完成状态，不自动去重。

Qwen在本地端点且带多维提示时使用较短提取提示词：只提取有原文依据的字段，不要求营养估计；真实本地调用最多两条/批，原文字符预算2000。此限制是保守工程预算，不是精确token保证，长单条仍需后续token打包改造。云端抽取提示词保留完整领域说明。

历史关联只在调用方显式提供`intent_pool`时有已知记录。主入口未补入共享历史池的部分继续unknown，不能伪装已经完成历史去重。needs_more_context是提示，不是本轮实现的持久等待调度器。

## 配置

在`local-config.json`的`kev`段设置：

```json
{
  "annotation_mode": "dimensions",
  "dimension_batch_size": 1,
  "dimension_min_confidence": 0.72,
  "goals": ["戒烟", "找工作", "学英语", "健身减脂"],
  "event_gate": false
}
```

`dimension_batch_size`限制为1–4；15问题/来源，不沿用旧20条批次。未设置annotation_mode的旧配置保留`legacy_gate`行为。回到旧单类别实验可显式设置`legacy_gate`，但它不能消费新版十一维作自动删除依据。

旧`~/apps/sv-bench/kev_prompts_v10.py`和V14/V15及成绩文件保留，不覆盖金标、不把本次契约测试当模型准确率。本轮没有对旧11维评分程序做静默改版。
