# Steve Jobs 产品视角审阅报告（2026-10-16）

> 评审视角：Steve Jobs 思维操作系统（Focus = Saying No / The Whole Widget / Technology x Liberal Arts）

## 一、核心诊断结论：核潜艇仪表盘病（Engineering Vanity）

当前 Life Logger Web 端拥有 10 个主导航按钮、16 个卡片与工作台面板。
严重违背了“Focus is saying NO to 1,000 things”原则。把底层机房的电缆、ASR 槽位、声学分类、Token 监控全部大剌剌暴露在正餐第一屏。

## 二、四大结构性冗余（建议彻底砍掉或收敛）

1. **三张卡片说同一件事**：
   - “今日简报”、“每日记录”、“全天生活仪表盘”同时并存，争抢首屏注意力。
   - 必须三合一：顶部展示今日一句话精要 + 关键数据；主体只留纯粹的时间轴。
2. **工程师自我感动的伪需求**：
   - “声学环境场景分布”（显示听了百分之几的 stream、music、speech）。
   - “社交发言比例”。
   - “同网录音会话”。
   - “Doctor 诊断”。
   - 这些属于内部调试工具，不属于面向生活记忆的产品。应全部收敛进隐藏的“开发者设置”。
3. **丑陋的 API 裸露卡片**：
   - “口语补录与快速订正”占满首屏中央，直接把表单界面推给用户。应改为快捷轻量的全局浮动输入框或微信自然语言对话。
4. **低频死数据 Tab**：
   - “规律观察”与“周/月统计”目前只产生机械死板的计数。洞察应由 AI 在周报中自然告知，而不是做成单独的冷清图表。

## 三、真正的产品灵魂三要素（目标极简形态）

1. **Timeline（看今天）**：极度纯粹的时间轴，点击任意事件毫秒级回放原始手表录音（重现记忆的魔法瞬间）。
2. **Commitments（待办与账单）**：干净的我答应的事（Todo）和我付出的钱（Bill），做完划掉。
3. **Brain（问记忆）**：正上方极简交互框，用人类自然语言直接向生活记忆提问。
