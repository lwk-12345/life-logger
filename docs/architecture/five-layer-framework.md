## 五层

1. 采集：手表录音、定位、健康、睡眠；Mac 前台应用。
2. 转写：语音转文字、声纹、人声或外放判断。原文永久保留。
3. 理解：大模型读一遍，产出活动卡，每条细节带事实类型和原话。
4. 校验：代码核对本人、是否发生、原话、金额。去向只有入账、待确认、无关，不静默拒绝。
5. 展示：瀑布图、账本、饮食、吸烟、健身、日报都读同一份结果。

旁路：
- 对账线：代码扫转写原文，和账本、饮食、吸烟记录比对，有原话没入账的进“需要我判断”。不调模型，独立于第 3 层。
- 数据飞轮：用户的回答回流第 3、4 层。

消费、饮食、吸烟、健身、待办都是同一种事实，靠事实类型区分，不各建一层。
