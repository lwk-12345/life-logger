# Life Logger 北京时间归档口径

用户决定：Life Logger 所有时间线以 `Asia/Shanghai`（北京时间）归档和展示，不随 Mac 或浏览器时区改变。

- 原始录音、转写、事件的带偏移 ISO 时间戳保留原值；比较与排序按同一绝对时刻进行。归档日期、时间刻度和日界线由绝对时刻转换到北京时间得到。
- “今天／昨天”、默认查询日、周几、日历导航、日报范围、录音覆盖、事件／健康时间线统一用北京时间。纯日期 `YYYY-MM-DD` 是北京时间的日期标识，不经浏览器本地午夜解释。
- 新处理任务及 Watch ASR 的日期目录使用北京时间；延迟上传按真实采集时刻归档，不按 Mac 上传日搬移。未知发生时间仍未知，不能以归档日或接收时刻补造。
- 事件说话时间、发生时间、上传时间及处理时间分别保留。现场提问的发生与其请求内容的计划不混淆。
- 手动日期时间输入在产品内按北京时间解释并明确标识；外部带时区的输入保留原始绝对时刻。
- Mac 前台／输入法日志先按源日志真实时区解释，再转换到业务时区；不能把美国本地墙钟直接当北京时间。
- 系统时区、设备时钟、历史音频及历史交易不修改；既有历史按只读投影视图转换，不批量重算或移动原始文件。

## 验收

同一绝对时刻，在进程／浏览器处于上海、洛杉矶、UTC 时，日界线结果相同。覆盖北京时间午夜前后、洛杉矶夏令时切换、显式历史查询日、跨日录音和延迟上传。

- `2026-10-25T15:59:59Z` → 北京 `2026-10-25 23:59:59`。
- `2026-10-25T16:00:00Z` → 北京 `2026-10-26 00:00:00`。

只有完成独立验证、部署及实际页面／接口验收后才能标记整项完成。
