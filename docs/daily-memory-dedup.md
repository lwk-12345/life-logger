# DAILY MEMORY 去重与 ASR 后处理规则

本规则只影响展示/抽取质量，不修改七类事件契约。

## 去重

用户可见时间轴/工作台采用“时间窗 + 语义相似度”的组合：

- 默认事件：180 秒内才比较重复。
- 饮食、运动：600 秒内比较，覆盖一次行为被连续口述/ASR 切成多段的情况。
- 待办：900 秒内比较；跨日 NEXT 还会按待办意图文本继续归并。
- 文本判定：标准化后完全相同、较长子串高度覆盖，或 3-gram Jaccard >= 0.64。
- 饮食补充结构化判定：相同 `food.item/items`（例如“纯牛奶”与“牛奶”归一为牛奶）可直接视为同一短时行为。
- 待办会去掉“提醒我 / 记得 / 明天要 / 我需要 / 需要”等动作外壳再比较意图。

对话中的泛化“需要”不会自动成为 todo：问题句、比较句、以及“满足一个需要”这类描述会被过滤；明确“提醒我/记得/待办/明天要”或可执行的“我需要去/把/做/提交…”才进入 NEXT。

## 本地 ASR 后处理

高影响但高置信的领域词在事件抽取前做本地纠错，同时保留原始 ASR：

- 买烟/换口味等购买语境：`短剧的乐土`、`短支的乐土`、`短致的乐土` 等 → `短支的乐途`。
- 原始文本保存在事件 `evidence.raw_quote`，纠错记录保存在 `evidence.text_corrections`。
- `花16买...` 这种没有“元/块”单位、但有明确“花 + 数字 + 买”的句式会抽取 `amount=16.0`。
- 饮品出现 `九百五十九百升` 一类明显异常的大量“升”单位时，不猜具体毫升数；事件置信度降到 <=0.55，并写入 `review_required/review_reasons` 让用户确认。

已有历史产物不会被原地改写；DAILY MEMORY Web 对已存事件提供同样的文本纠错、金额回退解析和去重，因此旧的 9/21 结果无需先重跑才能正确显示 ¥16 与“短支的乐途”。
